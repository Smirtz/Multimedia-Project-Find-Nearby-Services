# Find Nearby Services (Multimedia Project)

This project implements all required components for the assignment:

- ✅ HTML and CSS
- ✅ Canvas API (interactive schematic map with pins + filters)
- ✅ Audio API (Web Audio: clicks + pings + ambient toggle + volume)

Bonus:
- 📍 Geolocation demo: **Locate Me** updates the “You” dot on the schematic canvas map.

## How to run
1. Open the folder in **VS Code**
2. Use **Live Server** (recommended)
3. Open `index.html`

## What to test
### Canvas API
- Filter buttons (All / Restaurants / Gas / ...)
- Click near a pin to select it (highlight + label)
- “You” dot is drawn on the canvas

### Audio API
- Click **Enable Audio**
- Change filters (click sound)
- Select pins (ping sound)
- Toggle **Ambient** and adjust **Volume**

### Geolocation
- Click **Locate Me** and allow location access
- The “You” dot moves based on your current coordinates (projected onto the schematic map)
